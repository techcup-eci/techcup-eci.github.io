## Identity manual

The identity manual shows the main elements the platform should contain in terms of the visual components. 
It explains the logo, chosen color palette and fonts in order to keep a professional yet refreshing and casual tone. 
Also, it provides a small context by providing both the mission and vision of the product. 

The Identity Manual (created with Latex) is available on the following link. 
[Identity Manual](https://www.overleaf.com/read/ngqxqtwrmzgj)
