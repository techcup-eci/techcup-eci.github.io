## Context diagram description

The context diagram presents the TECHCUP Football Platform as the central system that manages all tournament-related activities.

The platform interacts with different actors, including participants, captains, organizers, referees, administrators, and an external payment coordinator. Each actor communicates with the system according to their role.

Participants register, manage profiles, join teams, and consult tournament information such as schedules, results, and standings. Captains extend these actions by managing teams, inviting players, submitting payment proofs, and defining lineups.

Organizers configure tournaments, review payments, and register match results, while referees consult their assigned matches. Administrators oversee the system through role management, monitoring, and administrative controls.

The payment coordinator is an external entity, since payments are handled outside the platform and later validated within the system.
